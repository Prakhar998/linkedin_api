GETTING STARTED:
================

Step 1: Setup environment
$ bash setup.sh

Step 2: Extract LinkedIn credentials
$ python3 extract_credentials.py

Instructions:
1. Go to LinkedIn.com, log in
2. Open DevTools (F12)
3. Application > Cookies > linkedin.com > find 'li_at'
4. Network tab > any request > Request Headers > 'x-csrf-token'
5. Paste both values when prompted

Step 3: Run API
$ python3 app.py

Step 4: Test
$ curl http://localhost:5000/health
$ curl "http://localhost:5000/api/v1/profile?url=https://www.linkedin.com/in/username"

API ENDPOINTS:
==============
GET  /health - Health check
GET  /api/v1/profile?url=<url> - Get profile
POST /api/v1/profile/batch - Get multiple (max 10)
GET  /api/v1/docs - API docs

DEPLOYMENT:
===========
Docker:
$ docker-compose up

Heroku:
$ heroku create app-name
$ heroku config:set LINKEDIN_CSRF_TOKEN=token LINKEDIN_LI_AT_COOKIE=cookie
$ git push heroku main

Google Cloud Run:
$ gcloud run deploy linkedin-api --source .
